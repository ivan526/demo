# 发货备注 Bookmarklet 信息采集清单

为了让 Bookmarklet 能稳定读取发货页面、按规则生成备注并复制到发货系统，请按本文清单提供脱敏后的页面与接口信息。密码、Cookie、Token、真实姓名、电话、地址、订单号等敏感信息必须删除或替换。

## 1. 目标页面

- 发货页面 URL 的结构（域名可脱敏，但请保留路径、查询参数的结构）。
- Bookmarklet 在哪个页面、哪个操作阶段运行。
- 页面是否使用 iframe、Shadow DOM 或前端单页路由。
- 支持的浏览器及最低版本。
- 一笔发货是否可能包含多台样机；若包含，备注是整单一条还是每台一条。

## 2. 页面字段

请为每个参与规则判断或备注生成的字段填写一行：

| 业务含义 | 示例值（脱敏） | CSS 选择器或定位方式 | 控件类型 | 是否异步加载 | 缺失时如何处理 |
| --- | --- | --- | --- | --- | --- |
| 样机用途 | Demo / Evaluation | 例如 `[data-field="purpose"]` | 文本/下拉框 | 是/否 | 阻止生成/忽略/使用默认值 |
| 发货国家 | DE | 例如 `#ship-country` | 文本/下拉框 | 是/否 |  |
| 产品名称 | Device A |  |  |  |  |
| 数量 | 2 |  |  |  |  |
| 现有备注 |  |  | 文本框/富文本 |  | 追加/覆盖/去重 |

最好同时提供：

1. 相关 DOM 的最小 HTML 片段（包含稳定的 `id`、`name`、`data-*` 属性及必要父级）。
2. 页面截图，并标注字段与最终备注输入框。
3. 字段值的完整枚举及其业务含义，而不只是单个示例。

不要依赖易变化的样式类名或 `nth-child`；如页面没有稳定定位属性，请说明是否可以给目标元素增加 `data-*` 属性。

## 3. 请求信息

如果信息来自接口而非页面 DOM，请提供浏览器开发者工具中“Copy as cURL”内容的**脱敏版本**，或按以下格式描述：

- 请求方法与 URL 模式。
- 请求参数或 JSON body 示例。
- 响应 JSON 示例，以及各字段含义。
- 请求何时发起、一次页面操作是否会发起多次。
- 鉴权方式只需说明类型；不要提供 Cookie、Token 或密钥。
- 是否允许 Bookmarklet 复用页面当前登录态调用该接口。

优先读取页面已经获得的数据，避免重复请求；必须请求接口时，需要确认同源策略、权限与内部安全要求。

## 4. 规则定义

规则建议以“优先级 + 条件 + 输出 + 合并策略”的形式提供：

| 规则 ID | 启用 | 优先级 | 条件（全部/任一满足） | 输出文本 | 合并策略 | 示例 |
| --- | --- | --- | --- | --- | --- | --- |
| label-not-for-sale | 是 | 100 | 用途=Demo 且国家不在豁免清单 | `Print "NOT FOR SALE" label.` | 追加且去重 | Demo + DE → 输出 |

还需明确：

- 多条规则同时命中时，按优先级全部输出，还是命中后停止。
- 输出顺序、换行、标点、大小写及中英文要求。
- 国家使用中文名、英文名、二字码还是三字码；是否需要国家别名归一化。
- 空值、未知值、接口失败时，是阻止生成、提示确认还是继续生成。
- 已有备注如何处理，以及重复执行时是否必须保持幂等（推荐保持幂等，避免重复备注）。
- 规则由谁维护；第一版可使用版本化 JSON 配置，后续再决定是否需要管理界面和远程配置。

## 5. 操作与交互

请确认期望流程：

1. 点击浏览器书签。
2. 程序读取并展示已识别的页面信息。
3. 按优先级计算命中规则，并展示命中原因。
4. 用户可预览、必要时编辑备注。
5. 点击“复制”，写入剪贴板；可选地自动填入备注输入框。

还需确认是否允许自动填入或自动提交。默认建议只复制、不自动提交，以便用户最终核对。

## 6. 验收样例

请至少提供以下脱敏用例，预期备注需精确到换行和标点：

- 3 个常规命中用例。
- 2 个多规则同时命中用例。
- 2 个不命中任何规则的用例。
- 2 个字段缺失或未知值用例。
- 1 个重复运行用例，用于验证不会重复追加备注。

示例：

```json
{
  "input": {
    "purpose": "Demo",
    "country": "DE",
    "quantity": 2,
    "existingRemark": ""
  },
  "expectedMatchedRules": ["label-not-for-sale"],
  "expectedRemark": "Print \"NOT FOR SALE\" label."
}
```

## 7. 安全边界

- 不在 Bookmarklet 源码、规则配置或日志中保存凭据和个人敏感信息。
- 不把页面数据发送到第三方服务；若确需远程规则服务，应先明确数据范围、权限和审计要求。
- 第一版默认不自动点击“提交/发货”等不可逆按钮。
- 对未识别页面、字段冲突和规则异常给出明确提示，不静默生成可能错误的备注。

收到上述材料后，可以先实现“页面适配器、可排序规则引擎、备注预览与复制、配置校验、单元测试”这一最小版本，再根据实际使用反馈扩展规则管理界面。
